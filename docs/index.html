Quick start

From zero
to building.

Install the CLI with the Rialo SDK, add the userscript, or run the offline SCALE simulation.

About the CLI rialo-cdk provides Python bindings. The SDK requires a compatible Python and platform. This project pins 0.1.0. A Linux source build requires Rust and Cargo; see the README for supported environments.
bash / terminal
# Clone and install the toolkit and SDK
git clone https://github.com/sery2013/Rialo_DevKit
cd Rialo_DevKit
python -m venv .venv
source .venv/bin/activate
pip install -e '.[sdk]'

# Create an encrypted wallet
rialo wallet create

# Replace the RPC URL and recipient with real values
rialo --rpc https://YOUR_TESTNET_RPC balance
rialo --rpc https://YOUR_TESTNET_RPC send --to YOUR_PUBLIC_KEY --amount 1.0

How SCALE works

From request to resolution.

The conceptual SCALE flow. The included example simulates the state transitions locally; it does not connect to Rialo.

01 / CREATERequester

Creates a task with escrow and a deadline.

02 / NOTIFYRialo Chain

Notifies the worker through A2A.

03 / SUBMITWorker Agent

Submits work before the deadline.

04 / VERIFYJudge Agent

Verifies quality via webcall.

05 / SETTLERialo Chain

Resolves the task based on the result.

PASS → releases paymentFAIL → refunds requester
