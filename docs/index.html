Components

Three tools, one toolkit

Every component works independently. Use what fits your workflow.

🖥

Python CLI

Create and manage encrypted wallets, sign messages, check balances, and submit transfers via the Rialo SDK. Rich terminal UI with progress bars and formatted output.

rialo-cdk rich wallet sign send
🧩

Playground Userscript

Tampermonkey script that runs directly on playground.rialo.io. Scans visible transaction links, collects them into a panel, and exports to CSV. No keys touched, no background requests.

tampermonkey userscript csv-export playground
⚖️

SCALE Demo

An in-memory state machine demonstrating Rialo's Simple Contracts for Agent Labor Execution — escrow creation, task submission, judge verification, deadline expiry, and automatic refunds.

Installation

Up and running in minutes

Requires Python 3.10+. The core package and Rich install together. The SDK extras add wallet and network commands and need Rust/Cargo on Linux.

# Clone and install
git clone https://github.com/sery2013/Rialo_DevKit
cd Rialo_DevKit
python -m venv .venv
source .venv/bin/activate
pip install -e .
rialo --help
# Install with SDK extras for wallet + RPC
pip install -e '.[sdk]'

# Create a wallet
rialo wallet create
rialo wallet show

# Sign a message
rialo sign "hello rialo"
# No SDK needed — pure Python
python examples/scale_demo.py

# Outputs three scenarios:
#   ✓ Task approved by judge
#   ✗ Task rejected → refund
#   ⏱  Deadline expired → refund

About Rialo

What is Rialo?

Rialo is a Layer-1 blockchain by Subzero Labs, built for AI-agent workflows. It introduces Reactive Transactions, native webcalls (Rialo Edge), sub-second data feeds (Rialo Stream), and Stake-for-Service — gas credits funded automatically from staking yield.
